# Read-only paired host MCP fixture (ABR-94)

`index.mjs` exposes `connectLocalHostAgent({ endpoint, agentToken, deviceId, workspace })`. It establishes an **outbound WebSocket connection only to an explicit IPv4 `ws://127.0.0.1:<port>/agent` endpoint; ambiguous `localhost` DNS/IPv6 resolution is rejected**, authenticated by a separate >=32-character secret and fixed device identity. Neither inbound internet access nor external relay registration is enabled.

The only tool handler is a bounded UTF-8 `read_file` scoped to an approved absolute workspace. On Linux, it validates the originally authorized workspace device/inode and walks pinned directory descriptors via /proc/self/fd with O_NOFOLLOW for every component, including secure resolution of allowed in-workspace symlinks; attempts to swap a parent or the root fail closed. Other platforms require their own safe opener in ABR-96/97. It refuses root directories and nonregular files, caps file contents at 256 KiB and complete serialized WS responses at 512 KiB, rejecting oversized JSON safely and using nonblocking descriptors to reject FIFOs, while implementing bounded line pagination with full-source SHA-256. It does not spawn commands, fetch external URLs, upload source files, write content or call Linear/GitHub. Requests through `tools/call` are checked again by the relay.

**This is not an OS filesystem sandbox.** ABR-96 must add race-resistant, OS-principal-enforced authorization before production process/file handling. ABR-97 must validate host enrollment, macOS identity and revocation. Test with `node --test scripts/test-mcp-foundation.mjs` and review [ABR-94 decisions](../../../docs/audits/mcp/README.md).

## ABR-96 — Sandboxed executor and asynchronous jobs (not activated)

The **separate** `execution-service.mjs` composes `execution-authority.mjs` (private, expiring/revocable server-issued capability, rechecked at command launch and immediately terminating its in-flight/queued operations on revocation), `sandbox-runner.mjs` (Linux Bubblewrap namespaces, pinned directory-FD workspace mounts, no network/host filesystem, `prlimit` CPU/memory/file/output bounds and process-group teardown), `async-jobs.mjs` (session-owner scoped SQLite outcomes with WAL, idempotency, transactional all-or-nothing parallel job batches and bounded fair queue), and `terminal-sessions.mjs` (interactive Python REPL stdin, append-only arrival-ordered stdout/stderr segment cursors, prompt detection, bounded finished-session retention and scoped kill). This module **does not change** the existing `index.mjs` read-only paired agent or `bridge/server/mcp-relay`; ABR-97/98 must add an authorized tool adapter. No unsandboxed fallback is possible.

The current Ubuntu `bridge` UID 994 cannot create the required user namespace because of AppArmor; the strict [readiness probe](../../../scripts/mcp-executor-probe.mjs) exits 2. A narrowly approved host AppArmor policy and a successful real-`bridge` run are **mandatory before deployment**. Root-only isolated proof is not service-user acceptance. See the [full ABR-96 implementation and rollback](../../../docs/audits/mcp/EXECUTOR.md) and `node --test scripts/test-mcp-executor.mjs`.

## ABR-97 — Mac host enrollment and device-isolated routing

`device-enrollment.mjs` maintains operator-approved, signed Ed25519 device challenges and an audited SQLite registry for `macos-runtime` and `rebel-server`, with session-generation invalidation on pause, revoke, re-enrollment and dual-key rotation. `device-routing.mjs` requires external trusted human or Linear job admission; client-supplied target IDs cannot authorize another device, and interactive requests have no automatic Ubuntu fallback. `macos-host-probe.mjs` uses pre-trusted SSH to inspect an existing Mac launchd agent's OS user, Node and project root without deploying new code. All source-only; privilege and host-tool dispatch are deferred to reviewed ABR-98/99 integration. Full [ABR-97 evidence, host config and acceptance gates](../../../docs/audits/mcp/MACOS_HOST.md).

## ABR-98 — REPL, Git, structural AST and offline PDF adapters

`process-state.mjs` provides deterministic prompt detection now used by `terminal-sessions.mjs`. `git-readonly.mjs` invokes only scoped, fixed structured Git arguments inside the required Linux namespace. `ast-structured.mjs` uses reviewed `@babel/parser@8.1.2`, safely scoped reads and source SHA-256; rewrite is dry-run by default, and mutating writes are denied without a separately vetted atomic writer. `pdf-offline.mjs` uses pinned `pdf-lib@1.17.1` (MIT) for bounded PDF generation/editing without browser downloads; a distinct `write_pdf` grant and injected atomic output handler are required. No production Mac/Ubuntu executor tools are enabled by this source change. Dry-run AST unified diffs now retain exact final-newline semantics (including CRLF and `\ No newline at end of file`), validated by real `git apply --check` and exact-byte round-trip fixtures. Rewrites detect ambiguous matches regardless of `maxResults`. Git uses `--literal-pathspecs` and excludes special `@`/`+` selectors. Details: [ABR-98 profile audit](../../../docs/audits/mcp/PROFILES.md).
