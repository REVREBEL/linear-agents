# Documentation and policy work orders

Use for README, ADR, guides, schemas, policy writing, documentation reviews and process refinements.

1. Confirm audience, authoritative sources, scope, document owner and whether the change is a new decision or explanation of an existing contract.
2. Preserve established terminology and links; distinguish approved decisions from proposals and historical material.
3. Check internal consistency, cross-reference accuracy, broken links and that new policies do not duplicate higher-authority instructions.
4. **PASS** requires all requested sections, valid references, coherent decisions and suitable handoff. Unit tests, SHA-256 manifests and full inventory counts are not intrinsically required.
5. Use a PR when editing repository documentation; otherwise attach/link the reviewed document in Linear.
