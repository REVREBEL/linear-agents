# Research-only and decision work orders

Use for literature/source research, architecture decisions, comparisons and recommendations when no repo code/artifact changes are requested.

1. Identify decision/question, source scope, freshness limits and what is excluded. Distinguish primary evidence from inference; cite accessible records.
2. Verify relevant existing decisions before proposing replacements, note contradictory evidence and unknowns. No requirement to run unit tests, hash every source or enumerate all skills unless the specific issue asks.
3. Produce the requested memo/decision table with alternatives, trade-offs, recommendation, confidence, open questions and exact sources.
4. **PASS** when the question is answered, sources and limitations are traceable, explicit issue-specific acceptance criteria are met, and unresolved questions are visible. **BLOCKED** when required sources are inaccessible or a decision cannot be substantiated.
5. For research delivered in Linear/connected docs, link the artifact and request review without an empty PR. A PR is required only for repository-backed research changes or when the issue explicitly demands one.
